# Потребление ресурсов: Python → Rust

Один и тот же production-сервер: Debian 13, 2 vCPU, 3.8 GB RAM, общий с другими сервисами.
Данные и токен бота одни и те же. Замеры сделаны в простое, без рассылок.

## Методика

- **Python (Docker).** Для каждого контейнера стека (бот, PostgreSQL, Redis) читались счётчики
  cgroup v2 `/sys/fs/cgroup/system.slice/docker-<id>.scope/`:
  - `memory.current`, `memory.peak`, `memory.swap.current`, `memory.stat` (anon/file);
  - `cpu.stat` `usage_usec`; средний CPU = `usage_usec` / аптайм контейнера.
- **Rust (systemd).** `systemctl show -p MemoryCurrent -p MemoryPeak -p MemorySwapCurrent
  -p CPUUsageNSec`, `memory.stat` юнита. RSS по `ps -o rss`: в него входят общие страницы
  бинарника, поэтому RSS больше, чем cgroup.
- Сравнивается сумма всего Python-стека с одним Rust-процессом.
- Процент CPU Rust-версии приводится только после суток работы. Сразу после старта
  сравнивается только память.

На эти цифры влияют и соседние сервисы, поэтому это наблюдение, а не контролируемый замер.

**Оговорки.** Замеры сделаны в простое. Скорость обработки и нагрузка во время рассылки
не сравнивались: рассылка в обеих версиях идёт с одинаковой паузой `1/RPS`.
Экономию CPU можно будет оценить только суточным замером.
